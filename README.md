# Procurement And Inventory Management Platform

## Overview

This project is a backend platform for managing procurement and inventory processes.
The objective is to simulate the development of a production-oriented business application using modern .NET technologies and engineering practices.
The project will evolve incrementally through multiple versions, incorporating architecture, testing, cloud deployment, observability, and documentation.

## Local development

This project uses .NET User Secrets for local sensitive configuration.
Configure the database connection: dotnet user-secrets set "ConnectionStrings:DefaultConnection" "<connection-string>" --project src/Procurement.Api

**Current status:** Under development.
